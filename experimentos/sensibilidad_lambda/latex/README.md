# Archivos LaTeX

`DRAFT_UPDATE_I00C_LAMBDA_SENSITIVITY.tex` contiene el texto completo en
español. Requiere en el preámbulo:

```latex
\usepackage{amsmath,amssymb,booktabs,graphicx}
```

Para conservar las rutas del bloque:

1. copiar `tabla_sensibilidad_lambda_i00c.tex` a `tablas/` del manuscrito;
2. copiar la figura PDF del directorio hermano `figuras/` a `figuras/` del
   manuscrito;
3. incorporar el bloque principal en la ubicación deseada del draft.

La tabla usa `booktabs`, no contiene colores y está preparada para impresión
académica en escala de grises.
